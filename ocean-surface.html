🚧 项目筹备中 · 代码即将开源  |  Under construction · Source code coming soon

项目简介 · About

WilhaoOceanSurface is an open-source digital twin platform for marine surface systems. It provides high-fidelity dynamic modelling, simulation, and visualisation for autonomous surface vehicles (ASVs), wave gliders, and related ocean-surface platforms, serving as a testbed for control, perception, and cooperation algorithms. The source code, datasets, and documentation will be released progressively on this page.

WilhaoOceanSurface 是一个面向海洋水面系统的开源数字孪生平台。 面向无人水面艇、波浪滑翔器等海洋水面平台，提供高保真动力学建模、仿真与可视化， 并作为控制、感知与协同算法的验证平台。源代码、数据集与文档将逐步在此开源。

规划内容 · Planned Features

  • Real-time simulation and visualisation  —  数字孪生实时仿真与可视化
  • Control & cooperation algorithm validation  —  控制与协同算法验证
  • Open datasets & documentation  —  开放数据集与文档
